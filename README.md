# Desk Recipe / デスクレシピ

React + TypeScript + Vite + Konvaで作成した、日本語・英語対応のデスク写真ラベルエディターです。

## 使い方

1. JPEG・PNG・WebPの写真をアップロードします。
2. 「ラベルを追加」を選び、写真上をクリック・タップします。選択モードは選択・解除だけを行います。
3. ブランド・製品名・任意の価格を入力し、ラベルをドラッグして配置します。
4. 文字枠上の四角いハンドルで接続点、丸いハンドルで製品側の先端を動かします。矢印の線をクリックしても選択できます。
5. 右下の斜線入りハンドルで枠をリサイズします。文字サイズは独立し、幅に合わせて折り返します。
6. 「くるくる」は連続したベジェ曲線です。青いひし形でループだけを移動し、「円の大きさ」で直径を変更できます。
7. PNG / JPEGで書き出します。書き出し後のプレビューにも保存リンクがあります。

スマートフォンは上にキャンバス、下に写真・ラベル・書き出しのボトムシートを表示します。2本指で拡大縮小・移動できます。

## 編集・保存

- 個別の価格表示を保持しながら、全表示・全非表示・個別設定を切り替えられます。
- 11種類のフォントを見本付きで比較できます。明朝・ゴシック・丸文字で絞り込めます。
- 文字サイズ・揃え・色・不透明度と、矢印の色・太さ・形状を個別に設定できます。
- コピー・貼り付け・複製・削除、Undo / Redoに対応します。
- Ctrl / ⌘ + C・Vはラベルのコピー・貼り付け、Ctrl / ⌘ + ZはUndo、Shiftを加えるとRedoです。入力欄では通常の文字編集を優先します。
- 写真と編集内容はIndexedDBに、ブラウザ内で自動保存します。写真をサーバーへアップロードする処理はありません。
- JSONに元画像を埋め込んで保存・再読込できます。自動保存は端末・ブラウザ・URLごとに独立するため、端末やURLを変える場合はJSONを保存してください。

## フォント

Zen Maru Gothic / M PLUS Rounded 1c / Kiwi Maru / Noto Sans JP / Noto Serif JP / Shippori Mincho / Zen Old Mincho / Nunito / Quicksand / Inter / Montserrat

Google Fontsから読み込みます。初回はインターネット接続が必要です。日本語グリフのないフォントでは日本語部分にZen Maru Gothicを使用します。

## 起動

Node.js 24以上で実行します。

```sh
npm ci
npm run dev
```

`npm run build`で公開用の`dist/`を生成します。静的ホスティングで動作します。
開発時の`/?qa=1`は、自動保存を変更しない確認用画面です。

## PWAと画像処理

本番ビルドにmanifestとservice workerを含みます。HTTPS上で対応ブラウザのインストール機能や「ホーム画面に追加」を利用できます。本体・サンプル画像はキャッシュし、未取得のフォントはオフライン時に代替表示します。

編集中のアップロード画像は最大長辺1600px。元画像Blobは別に保持します。幅1200の文書座標と、画面のズーム・パンを分離しています。
書き出し時は元画像に差し替えて再描画します。標準は長辺1920px、16:9では1920×1080です。元画像ベースでは選択比率の中央切り抜きと画素密度を保ちます。
4500万画素を超える出力やメモリ不足は、編集状態を保持して標準解像度を案内します。選択枠・操作ハンドルは書き出しません。矢印は文字枠を回り込む経路を計算し、線を切り取って隠す処理は使いません。

`components/`が画面とCanvas描画、`hooks/`が履歴・保存・ジェスチャー、`lib/`が座標計算・画像処理・入出力、`types/`がデータ型を担当します。

## 検証

`npm test`は接続点・枠変更・曲線ループ・出力解像度・JSON・クリップボードのデータ保持を検証します。
PC操作、390px幅のボトムシート、日本語・英語、フォント一覧、矢印クリック、接続点・枠・ループのドラッグ、価格の全体切替、PNG/JPEGの1920px書き出しをブラウザで確認しています。
実機のiPhone・Androidでの複数指ジェスチャーとPWAインストールは未確認です。

サンプル写真はユーザー提供の画像です。

GitHub Pagesではmainブランチのdocs/を公開します。npm run build後のdist/をdocs/へコピーし、docs/.nojekyllを含めます。アイキャッチは実写真と文字・図形の通常合成で制作しており、生成AI画像は使用していません。
